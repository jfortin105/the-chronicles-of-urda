# Traveling Numbers
- PCs can enter a number of hexes per day based on travel method:

| method  | hexes |
| ------- | ----- |
| Walking | 4     |
| Mounted | 6     |
| Sailing | 8     |

# Traveling Checks
- Weather event d6 check at start of day

# Rations
- PCs can go three days without consuming a ration
- PCs take 1 CON damage each day after that 
	- Death at 0 CON
- PCs can forage for 1 ration per day with an INT check
